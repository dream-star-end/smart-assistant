# Commercial release failure policy (OCV5-521)

User approval: commercial first, retaining CI and independent review. The approved #879/#880/#881 batch must wait for no in-progress commercial user rounds. Only actual user impairment permits rollback. Cache/G1/external/metadata failures stay nonzero and preserve a usable new service.

Use `--failure-policy=user-impact-only` with normal `--with-dist --egress` deployment. This is a per-invocation policy, not a production environment toggle. All original proofs, migration/capability/lossless floors, full smoke, functional dual-engine/J1-J5, frontend handshake, public assets, Plugin checks and mutation fencing remain. Default lanes preserve their policy. This first adapter requires the enabled runtime saga and existing dual-slot egress; unsupported legacy/source-only activation and setup-first mode reject before source exposure.

The immutable descriptor binds the queue-pinned source SHA, source manifest digest, four runtime keys/current, active slot/port, egress predecessor, deploy-state lineage, history prefix and exact shipped helper closure. The official remote flock/meta/admission nonce and this invocation's separate in-flight nonce fence all changes. No credentials, full environment or executable recovery commands enter the descriptor.

A healthy exact candidate can remain usable after a failed gate. Hold statuses 78/79 cross both saga and actual outer callers without old source/Plugin compensation; fencing loss is 86. Compatible current-target Plugin gates are reopened through official release validators. An unknown or incompatible Plugin remains unresolved; it is never falsely reported as usable. A proven failed master with its correct loopback refusing connections may use the original compatibility-guarded compensation. A private egress-health timeout alone cannot kill a possibly serving model process. Only a target-bound failed egress and actual refused shared port permit the original egress-only restoration; the healthy master stays new and deployment stays failed.

`--recover --failure-policy=user-impact-only` uses the same queue operation under a fresh official lease. Exact stack and frozen lineage are checked before forward CAS/history repair; lost acknowledgements are reread, unrelated/advanced state refuses. Egress can continue from the captured predecessor. Expected frontend build ID comes from the immutable target release. All original gates and official approved Plugin reconcilers run before verified forward acceptance. An exact accepted archive can finish only receipt cleanup without repeating paid gates. Active context and the existing manual recovery marker block new writes while unresolved.

Generic foundation and optional saga adapter are ported from personal #882 head87c39ccc; commercial orchestration is separate. Personal lease/watch/bootstrap code is not ported. The existing runtime activation and state-hook functions live in the mandatory commercial library to remain below the unchanged publisher size gate; tests read that actual source while retaining floor/flavor/argument assertions.

Verification belongs to the commercial PR: generic durable decision tests, real saga/legacy safety controls and red-green faults, actual commercial outer return paths, real closure shipping, actual remote holder flock/nonce checks, history checksum, exact archive recovery, existing runtime/egress/flavor/release safety tests and native CI. No production fault injection. Production acceptance additionally requires fresh frontend/runtime/egress identity, real Sol/Luna multi-turn/tools/300-second continuation/parallel canary, cache comparison and a complete new uid247 usage/finalize/ledger/wallet window. Historical #880 results are not new-batch evidence.

R2 recovery guarantees: a policy hold cannot block a necessary N1 rollback after real user impairment. `--rollback=1 --failure-policy=user-impact-only` admits only the exact typed context/marker, retains the unconditional mutation-in-flight barrier, and revalidates ownership and the complete physical candidate under the official lease. A failed candidate plus its refused loopback port is direct impairment evidence. For observed login/chat/billing impairment with a still-healthy process, an operator may additionally provide `--user-impact-evidence=<sha256 of retained raw evidence>`; the decision binds that digest to this exact operation/candidate. Merely failing a cache or external gate is insufficient. Forward recovery of a genuinely unavailable target uses this same guarded path.

Before a required rollback, only records of the observed target may be reconciled: the frozen deploy-state CAS and exact history prefix/checksum/sequence remain mandatory. The official N1 predecessor tuple must equal the frozen before tuple both before and after a missing target record is repaired. Original rollback compatibility, lossless, migration, capability and smoke gates still run, with a real per-operation saga recovery marker; the original typed intent/marker survive until complete verification. When the predecessor bundle axis was disabled, the original saga leaves `current` alone; the adapter restores only that disabled axis's frozen current, after proving the exact old env/source/healthy master and a current value belonging to this transition. Alien state is held. Recover gates bind Plugin SHA to the selected frozen release, never current HEAD or an empty/stale build variable. Compensated acceptance requires exact old source/tuple/current, both real history records, deploy-state lineage, egress, and all original gates. An unresolved private rollback marker prevents acceptance.

Egress recovery selects the exact process revision, not start-time order. A healthy target is bound by MainPID, cwd, InvocationID/start ticks and private health; the old socket closes before its service drains without blocking. Acceptance additionally requires every shared-port node listener to belong to the target PID. Both-active and interrupted reverse-pointer states are finite recovery paths, and an old listener that still accepts connections is a failure. A new attempt records its actual slot atomically under the operation and fresh owner; the initial slot is provenance, not a permanent direction lock. Proven actual egress outage permits only scoped egress compensation; if the old slot is draining, the free failed slot is preferred for immediate restoration. Unknown health, foreign processes, foreign pointers and fencing loss retain their failures. Recovery may use a newly reviewed helper bundle while preserving the immutable original descriptor and source/history identities; the bundle digest records provenance rather than preventing the approved controller fix itself from running.
