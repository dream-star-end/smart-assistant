# P3 native transport infrastructure — in progress

AGENT-REMOTE-T1555U. This draft implements infrastructure; it does not yet run a
production Worker, remote ToolHost or authenticated relay. No production caller
or activation change is present. P2 was merged as #1342 / 9826fe951.

The distinct native protocol checks scoped frames, directions, immutable operation
hashes, typed callbacks, artifacts and Writer delivery ACKs. Native journal rows
share the existing principal transaction/fences with the legacy file/process
journal, in a separate normalized table. Global DB format v2 deliberately rejects
existing v1 databases; it does not upgrade an already-open v1 writer. Principal
metadata remains explicitly v1. Final execution receipts seal their event prefix;
Writer artifact/transcript delivery is a separate ACK. Unknown observations cannot
occupy the immutable final receipt. Unacknowledged delivery blocks rebinding and
checkpoint publication.

Tool session state uses the real root store/reducers and bounded native file cache.
A producer independently drains real runTools; a lost progress consumer only
detaches. Complete validation/permission/hook/call/post-hook promises are tracked,
with a separate canonical-call guard. Disposal retains listeners until foreground,
registered background handlers and resources drain; it does not assert physical OS
process-tree exit.

checks; 26 native scheduler/lifetime/stream checks; gateway/references typecheck; Biome for the
new modules and affected agentRemote files. Full CCB typecheck still has baseline
errors, but its diagnostics exactly match the unchanged P2 source after fixing the

The Worker routing port now redirects the entire runToolUse pipeline before local
lookup/validation/permission/hooks. Both native schedulers await classification;
streaming reserves pending positions, retains original concurrency/exclusive

getAppState overlays. This is a trusted port with test transport; actual
scope/hash/incarnation/epoch authentication remains a separate adapter task.
The final cancellation guard and canonical call now share one continuation;
a negative fault injection reproduces the removed microtask race.

A supervisor-only SQLite Host ledger now consumes each whole pipeline once,
then separately commits effective input and canonical-call admission. Its logical
session watermark spans native UUIDs, while each native fence keeps its own
context/manifest. Fence installation and old-running -> unknown are atomic; late
receipts preserve original provenance. Current authority can read old native
history without reactivating its fence. A durable cancel tombstone handles cancel
before execute; cancellation after start requires actual supervisor exit evidence.
Final receipt/outbox commit together, reserve a terminal slot, and share control's
event-kind boundary. This remains an unconnected library, not an authenticated
execution endpoint. DB/WAL/SHM must stay outside tool-container mounts; current
container sudo/ptrace capabilities have not been changed or declared isolated.

## Native artifact durability and the actual Writer (increment)

`nativeToolArtifactPathAllowed` is shared by wire artifacts and checkpoints. It covers safe ordinary text/JSON spill IDs, MCP text/binary/resource output, WebFetch binary output, and nested PDF JPEG pages. Host ingress cannot write native main/sidechain transcripts or metadata. Tool-use IDs are separate opaque provider identity, including long Google replay signatures; the 8 MiB frame budget still applies and infrastructure IDs keep their stricter shape.

The streaming installer runs inside `withSessionFile`'s tracked mutation with an opaque process-local lease and the actual session UUID flock. It checks content size/hash, fsyncs a private stage on the native volume, installs without overwrite, verifies installed bytes, and syncs each visited directory and parent, including existing directories on retry. A crash between linking target and unlinking the operation's stage is recovered only after matching the same inode. Canonical cwd aliases require the actual locked transcript inode; a copied transcript is rejected.

Explicit `appendEntryToFile` dependencies and ordinary main/sidechain recorders carry typed immutable dependencies through the real Project queue into the JSONL patch. Artifact failure prevents the reference append. Dependencies filtered out or removed by UUID dedup fail explicitly. Queue admission and the installer hash are not a delivery ACK: durable prepared/commit records, reconciliation after append-before-ACK, and identical ACK resend are still pending.

Validation at this increment: 20 Node tests pass, including two real installer SIGKILL boundaries recovered by fresh Writer processes, existing PDF-directory parent-fsync EIO/retry, a 9 MiB streamed file, scope/lock/path/content/alias negatives and reentrant dependency rejection. The actual CCB writer suite passes 27 tests, including its existing file/queue cases and new main/sidechain dependency, conflict, failure and filtered/dedup negatives. Native protocol passes 12 tests including long/Unicode provider IDs and invalid/frame-budget negatives. These are synthetic local tests and no new real model call. This is a foundation increment, with no production bridge caller or P3 activation.
