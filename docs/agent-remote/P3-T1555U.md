# P3 native transport infrastructure — in progress

AGENT-REMOTE-T1555U. This draft implements infrastructure; it does not yet run a
production Worker, remote ToolHost or authenticated relay. No production caller
or activation change is present. P2 was merged as #1342 / 9826fe951.

The distinct native protocol checks scoped frames, directions, immutable operation
hashes, typed callbacks, artifacts and Writer delivery ACKs. Native journal rows
share the existing principal transaction/fences with the legacy file/process
journal, in a separate normalized table. Global DB format v2 deliberately rejects
existing v1 databases; it does not upgrade an already-open v1 writer. Principal
metadata remains explicitly v1. Final execution receipts seal their event prefix;
Writer artifact/transcript delivery is a separate ACK. Unknown observations cannot
occupy the immutable final receipt. Unacknowledged delivery blocks rebinding and
checkpoint publication.

Tool session state uses the real root store/reducers and bounded native file cache.
A producer independently drains real runTools; a lost progress consumer only
detaches. Complete validation/permission/hook/call/post-hook promises are tracked,
with a separate canonical-call guard. Disposal retains listeners until foreground,
registered background handlers and resources drain; it does not assert physical OS
process-tree exit.

Validation at this infrastructure snapshot: 59 targeted protocol/control/storage
checks; 26 native scheduler/lifetime/stream checks; gateway/references typecheck; Biome for the
new modules and affected agentRemote files. Full CCB typecheck still has baseline
errors, but its diagnostics exactly match the unchanged P2 source after fixing the
three new test diagnostics. No real upstream model requests or user containers.

The Worker routing port now redirects the entire runToolUse pipeline before local
lookup/validation/permission/hooks. Both native schedulers await classification;
streaming reserves pending positions, retains original concurrency/exclusive
barriers, drains in-flight work independently of discard, and propagates dispatch
unknown instead of fabricating a retryable tool result. Serial Skill modifiers
invalidate following plans using a stable context revision, including fresh-object
getAppState overlays. This is a trusted port with test transport; actual
scope/hash/incarnation/epoch authentication remains a separate adapter task.
The final cancellation guard and canonical call now share one continuation;
a negative fault injection reproduces the removed microtask race.

Remaining before activation: actual execution-side durable consume/fencing,
authenticated transport/reconnect and Host classification/admission adapters,
complete bootstrap/context and auxiliary model callbacks,
independent task/resource ledgers, real Writer artifact installation, model and
master authority relay, Worker supervision and all ingress paths. Remove non-Box
subscription print/OAuth routes while preserving interactive Box and legal API/Sand
usage. Then isolated real-native validation, official review/CI, personal train and
post-release acceptance. This document is not P3 completion or rollout evidence.
