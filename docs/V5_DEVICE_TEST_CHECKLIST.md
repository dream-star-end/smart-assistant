# V5 真机回归清单(每次前端批次上线后执行)

> roadmap P0.1 固定清单。执行人:boss(真机)。执行时机:任何涉及 web-react 的批次部署后。
> 记录方式:每项 ✅/❌+日期;❌ 直接开修复单(按 playbook §3 定位)。
> 维护:出过真机 bug 的场景**必须**加进本清单(jsdom 单测过 ≠ 真机过)。

## A. iPhone Safari(必测)

| # | 场景 | 步骤 | 通过标准 |
|---|---|---|---|
| A1 | 键盘收起留白 | 点输入框弹键盘 → 收起键盘(收起键/点空白) | 输入框回到屏幕底部,底部**无空白带**;来回 3 次不劣化 |
| A2 | 键盘弹起遮挡 | 长会话滚到底 → 点输入框 | 输入框浮在键盘上沿,不被遮挡;顶栏不被顶出屏幕 |
| A3 | 生成中上翻 | 发长任务,流式期间向上翻阅读历史 | 不被强制拽回底部;手动拉回底部后恢复跟随 |
| A4 | 切后台回前台 | 生成中切到其他 App 1 分钟再回 | 会话续上(内容不丢/不重复);"生成中"状态正确 |
| A5 | reload 恢复 | 生成中下拉刷新页面 | 历史完整;若 turn 仍在跑则续流,已结束则显示完整结果,不永久转圈 |
| A6 | 附件 | 拍照/相册各传 1 图 + 1 个 PDF | 缩略图出现、可点开灯箱、发送后 AI 能读到 |
| A7 | 地址栏收放 | 上下滚动触发 Safari 地址栏收起/展开 | 布局不跳、输入框不悬空 |
| A8 | 横竖屏 | 会话中旋转一次再转回 | 布局正常,滚动位置合理 |

## B. 鸿蒙 ArkWeb(必测)

| # | 场景 | 步骤 | 通过标准 |
|---|---|---|---|
| B1 | 图片附件 | 相册选 1 张图 | 附件缩略图**必须出现**(FileList 快照回归项) |
| B2 | 多选附件 | 一次选 2-3 个文件 | 全部出现,无静默丢失 |
| B3 | 下载 | 让 AI 生成文件并下载 | 系统下载组件能拿到文件(ticket 化 URL 回归项) |
| B4 | 键盘遮挡 | 同 A2 | 同 A2 |
| B5 | 上传格式 | 传一个非常见后缀文件(如 .tex) | 不 415 拒绝(accept 白名单回归项) |

## C. 团队模式专项(开启团队模式后)

| # | 场景 | 通过标准 |
|---|---|---|
| C1 | 委派可视化 | 发复合任务,能看到委派卡实时进度、成员状态、耗时;完成后可展开看子过程 |
| C2 | 中途停止 | 委派进行中点停止,整棵委派树终止,不留"永远运行中"卡 |
| C3 | 费用感知 | 团队模式开启有可见指示;模型选择器显示真实队长引擎(诚信三连回归项) |
| C4 | 同设备重开 | 关掉标签页重进,团队卡完整(跨设备丢失是已知债,不算失败) |

## D. 通用抽查(每次 3 分钟)

- 登录态:刷新不掉登录;深色/浅色主题切换正常
- 长消息:含代码块/表格/数学公式的回复渲染正常、可复制
- 用量页:本轮消耗有记录、余额变动一致
