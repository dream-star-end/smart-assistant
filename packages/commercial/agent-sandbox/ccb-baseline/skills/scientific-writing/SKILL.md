# scientific-writing 科研写作规范

科研写作的"正确性与呈现"交确定性层(oc-cite 接地、oc-report 排版),你的职责是**产出结构化、可接地、不浮夸的内容**。

## 结构(按文体)

- 研究报告:背景/问题 → 方法 → 结果(数据+图表)→ 讨论(局限+对比)→ 结论 → 参考文献。
- 文献综述:主题脉络分组,每条论断绑定文献,突出共识/分歧/空白,不堆砌罗列。
- 论文段落:每段一个论点,论点→证据(quote/数据)→解读;避免无支撑的概括。

## 引用接地纪律(硬性)

- **每个事实性论断必须有 quote 支撑**(来自 oc-litrag 的 verbatim quote),并经 oc-cite 校验。
- **绝不凭记忆写 DOI / 编造引用 / 杜撰数据**。没有证据就写"据现有资料未能确认"或标未核查。
- 正文用 `[[claim:<id>]]` 占位引用,交 oc-report 编号;参考文献由引擎生成,不手写。
- 区分"已证实 / 假设 / 争议",不要把推测写成结论。

## 去 AI 味(v3 用户高频反馈)

- 删套话:"在当今快速发展的时代""综上所述,值得注意的是""本文将深入探讨"。
- 少用空泛形容词堆叠("极其重要""至关重要的意义");用具体数字/机制代替。
- 句式有长短变化,别每段都"首先/其次/最后 + 三段排比"。
- 不滥用 emoji、不用营销腔;学术语体客观克制。
- 术语准确、前后一致;首次出现给全称 + 缩写。

## 生医/临床/政策

只给研究辅助与证据边界,不提供诊断/治疗/合规结论;高风险领域引用强制经撤稿过滤(oc-cite)。
