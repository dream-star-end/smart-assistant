一页简报，不只给结论，也给依据

规模与覆盖率，回答不同问题

印度尼西亚人口 2.79 亿，样本规模最大；越南联网率 78.59%，三个样本中最高。这不是同一种“领先”。

允许估算，但明确它是估算

将人口与联网率相乘，三个样本合计约 3.49 亿联网人数（派生近似量）。这不是产品客户数，也不意味着可直接触达。

把决策留给更完整的证据

人均GDP使用当年美元，不是个人收入。市场进入决策还需要行业需求、法规、渠道、成本与实地验证。
