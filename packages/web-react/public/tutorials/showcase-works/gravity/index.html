无量纲二维牛顿引力教学模型，G=1。采用速度 Verlet 积分，固定步长 0.002；引力软化 ε=0.025，防止近距离奇点。不是相对论模型，不处理碰撞与天体真实尺寸。上方误差相对最近一次干预后的能量计算；手动改变质量、位置或速度属于对系统注入能量。

八字初值参考 Chenciner & Montgomery（2000）的等质量八字解。本例加入软化，因此不是该精确解。近距离相遇可能增大数值误差；警示出现时请重置或换预设。
