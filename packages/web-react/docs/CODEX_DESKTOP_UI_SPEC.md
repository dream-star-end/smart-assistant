## 1. 总体布局与断点

### 1.1 栏结构

| 视口 | 布局 | 现状 | 标注 |
|---|---|---|---|
| `< 768px` | 单栏。左栏 Sheet 抽屉 268px / max 82vw | 已是 | `已满足`（改三栏不得破坏） |
| `768–1279px` | 两栏：左 268px + 中 flex-1 | 已是 | `已满足`；token 密度 `需改造` |
| `≥ 1280px`（`xl`） | 两栏或三栏：右栏仅当至少一块有数据时出现 | 现无右栏 | `需改造` + `依赖数据` |

Windows 本地 44px app bar 在产品区 **之外**，本规格不包含它。产品区高度 = 窗口 − 44px。

### 1.2 宽度

| 区域 | 目标 | 最小 | 折叠 |
|---|---|---|---|
| 左栏 | 268px（可后期 240–280） | 220px | 桌面可折到 0，顶栏出「展开」；移动始终抽屉 |
| 中栏 | `flex-1`，消息列 `max-w-3xl`（768px）居中 | 360px | 不折叠 |
| 右栏 | 280px | 240px | 用户可关；**无数据时不占位**（变回两栏） |

分隔：1px `var(--border)`，不要重阴影把栏做成卡片漂在画布上。左栏背景 `var(--sidebar)`，中/右 `var(--bg)`/`var(--surface)`。

### 1.3 验收点

- [ ] 390×844：汉堡打开抽屉，无第三列，输入框不被三栏挤没。`已满足` 为基线，后续 PR 回归。
- [ ] 1280×800：未绑仓库且无 todos → 只有两栏。`依赖数据`
- [ ] 1440×900：有仓库绑定或 todos → 三栏，中栏消息仍可读（`max-w-3xl` 或随中栏变窄后不溢出）。`需改造`
- [ ] 折叠左栏后中栏立刻吃满，焦点回消息/输入。`已满足`
- [ ] 右栏关闭按钮与左栏折叠不互相重置。`需改造`

## 2. 左栏

### 2.1 层级

1. 品牌 + 折叠  
2. 主按钮「新建会话」  
3. V5 一等入口：管理中心 / 市场 / 教程 /（组织）/（超管）—— **保留**，不因参考图没有而删除。`已满足` 功能；视觉 `需改造`（降低权重，避免压过会话列表）  
4. 搜索  
5. 会话列表：日期分组（今天/昨天/本周/本月/更早）。项目文件夹 **不画**。`依赖数据` → 无数据则保持日期分组  
6. 底栏账号  

可选：`pinned===true` 的会话置顶一组「置顶」。`依赖数据`（字段已有，UI 未用）→ 做了算 `需改造`，没立项保持现状。

## 4. 右栏（仅 xl 且有数据）

### 4.1 允许出现的分区

只允许这两块。**单实例：** `xl` 画在右栏时，中栏对应块必须卸载；`<xl` 只出现在中栏原位置。禁止两处同时渲染。

| 分区 | 数据 | 空时 | 中栏原位置 | 标注 |
|---|---|---|---|---|
| 仓库 | `RepoSelection.selected` | 整块不渲染 | `RepoPill` / `RepoStatusBanner` | `依赖数据` → UI `需改造`。文案是「绑定仓库 / 绑定分支 / 绑定时 HEAD」，不是 live 当前分支 |
| 当前任务 | `extractLatestTodos` 非空 | 不渲染 | `PinnedTaskTracker` | 数据 `已满足`；迁右栏 `需改造` |

**明确不进右栏（避免双权威）：**

- `AgentGate`：继续独占中栏并禁用 Composer。
- `PermissionCard`：继续走时间线 + modal。
- 委派/团队卡：继续走时间线 `TeamPanel` / agent-group。

分区可折叠（sessionStorage，不进偏好 DB）。仓库卡只显示 `owner/repo`、绑定 `branch`、`status`、短绑定时 `headSha`。**禁止**无 API 的 +/- 大数字，禁止把 bind 快照标成「当前分支」。

### 4.2 禁止出现（验收反例）

- 假的 `+297,244 −3,882`
- 文件树 / 「筛选文件…」
- 剪贴板来源列表
- Commit & Push / Create PR 产品按钮
- 「本地」环境（V5 会话在容器里）
- 16 running worktrees

出现任一项 = 本规格 FAIL。

### 4.3 右栏状态

| 状态 | 验收 |
|---|---|
| 全部空 | 右栏 DOM 不占宽度 |
| 仅仓库 | 一卡 + 折叠头 |
| clone 中 | cloning 进度，与现 RepoStatusBanner 同源，不要第二套状态机 |
| failed | 错误文案 + 可重新绑定，不显示假 branch |
| 超长 todo | 分区内滚动，不撑高整列把 Composer 顶没 |

## 5. 设置页

### 5.1 信息架构（只含 V5 已有能力）

**左导航分组（建议）**

- 个人：账户、用量与计费、偏好（含外观主题）、快捷键、反馈、关于  
- 工作区：GitHub 绑定说明（链到会话 Repo 或只读说明「在对话输入区绑定」）、插件（深链管理中心 connectors）  
- 不出现：宠物、Worktrees、Finder、菜单栏、终端位置、电脑视觉、钩子、已归档聊天、语言假选项  

**壳（拍板已定，实施不得再分叉）：** 与 ManageCenter 相同的近全屏 Dialog（`size="xl"` + `fixedHeight`）+ 左侧导航，**不是** `/settings` 新路由。打开/关闭仍走现有 `openSettings(section)`，URL 仍是 `/` 或 `/s/:id`。Esc / 点遮罩 / 返回关闭后焦点回到触发控件。

**`<md`（390×844 强制验收，不是「可用」）：**

- 禁止并排 master-detail，禁止横向溢出。
- 左导航变为 Sheet 或顶部可滚动 tabs（二选一，PR2 内定死并写测试）；五个现分区都必须能切到。
- 内容区独立滚动；长设置项（流水、快捷键列表）不把关闭按钮顶出屏。
- 返回：Sheet 关导航不等于关设置；关设置回到聊天。
- 焦点：打开设置焦点进标题/关闭钮；关闭后回触发按钮。

### 5.2 右侧行式控件

每一项一行：

- 左：标题 `text-section font-medium` + 说明 `text-caption text-faint`  
- 右：Switch / Select / 链接按钮，垂直居中  
- 行高 56–72px（有两行说明时取高）；分组标题 `text-meta uppercase faint`  
- 分组间 1px border，不要每行都画满横线  

对照：

| 控件 | 组件 | 标注 |
|---|---|---|
| 开关 | `ui/Switch`，开态 `bg-accent`（紫，保持 AA；不改为系统蓝除非重测） | `已满足` 组件；行布局 `需改造` |
| 下拉 | `ui/Select` 原生 select | `已满足` |
| 链接/按钮 | `Button variant=ghost/secondary` 或文字链接 accent | `已满足` |
| 字段原语 | 现 `Field` 是上标签下控件，设置页不要误用成行式 | `需改造`（可新增 `SettingsRow`，不要改坏表单 Field） |

### 5.3 设置各分节验收

| 分节 | 必须能完成的事 | 标注 |
|---|---|---|
| 账户 | 看余额、开通/管理订阅、流水、组织入口 | `已满足` 功能；布局 `需改造` |
